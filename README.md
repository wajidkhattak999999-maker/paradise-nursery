
# e-plantShopping - Paradise Nursery Shopping Application

Welcome to **e-plantShopping** (Paradise Nursery), an online shopping application designed for plant lovers! This web application allows users to browse a diverse catalog of indoor houseplants, view details including plant thumbnails, names, descriptions, and prices, and manage their shopping cart with real-time total calculations.

## Project Name Details
- **Project Name:** e-plantShopping
- **Application Name:** Paradise Nursery Shopping Application
- **Platform:** React, Redux Toolkit, CSS3, Vite

## Features
- **Landing Page:** Welcoming hero section with background image, company branding ("Welcome to Paradise Nursery"), and a "Get Started" button.
- **About Us Section:** Highlighting our mission, values, and passion for indoor gardening.
- **Product Catalog:** Grouped into 3 distinct categories with at least 6 unique houseplants per category (18+ plants total) featuring thumbnails, names, descriptions, and prices.
- **Add to Cart:** Real-time item additions, dynamic cart count badge, and button disabling upon selection.
- **Shopping Cart Management:**
  - Dynamic total cart amount calculation.
  - Individual plant total cost calculation.
  - Quantity increment and decrement controls.
  - Delete/remove item functionality.
  - "Continue Shopping" button returning to catalog.
  - "Checkout" button with "Coming Soon" notification.
